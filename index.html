Satu aplikasi, peran yang jelas

Super Admin mengelola pembukuan, Karyawan fokus mencatat transaksi.

Super Admin

Kendali penuh atas pembukuan.

  • Kelola data master: barang, pelanggan, pemasok, karyawan
  • Posting dan koreksi jurnal umum
  • Akses semua laporan keuangan
  • Kelola pengguna dan peran di aplikasi
  • Ganti password sendiri

Karyawan

Fokus mencatat transaksi harian.

  • Catat transaksi harian ke jurnal umum
  • Lihat laporan sesuai izin dari admin
  • Ganti password sendiri
  • Fokus pada pencatatan transaksi, tanpa menu laporan
